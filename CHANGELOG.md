# Changelog

Todas as mudanças relevantes do projeto são documentadas aqui. O versionamento segue `MAJOR.MINOR.PATCH`.

## [1.3.0] — 2026-11-04

- Reposiciona o botão de alternância para abaixo do cabeçalho da conversa, evitando sobrepor a foto e o nome do contato.
- Recalcula a posição quando o layout é alterado.

## [1.2.0] — 2026-11-04

- Remove divisórias residuais entre a coluna de contatos e a conversa nos modos compacto e oculto.

## [1.0.0] — 2026-11-04

- Introduz os modos Normal, Somente fotos e Oculto.
- Adiciona popup de controle, atalho de teclado e persistência local.

> Histórico baseado nas versões distribuídas anteriormente. Este repositório não contém tags Git retroativas para essas versões.
